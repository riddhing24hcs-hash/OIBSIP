# BMI Calculator – Python Project

## Project Overview
The BMI Calculator is a Python-based desktop application developed using Tkinter. It calculates the Body Mass Index (BMI) based on the user's weight and height and displays the corresponding BMI category.

## Features
- User-friendly graphical interface.
- Accepts name, weight and height.
- Calculates BMI automatically.
- Displays BMI category.
- Colour-coded BMI results.
- BMI category reference guide.
- Maintains calculation history during the application session.
- Clear input fields and clear history options.
- Input validation and error handling.

## Technologies Used
- Python
- Tkinter
- VS Code

## BMI Formula

BMI = Weight (kg) / Height (m)²

## BMI Categories

| Category | BMI Range |
|---|---|
| Underweight | Below 18.5 |
| Normal Weight | 18.5 – 24.9 |
| Overweight | 25 – 29.9 |
| Obese | 30 and above |

## How to Run the Project

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
py gui.py
```

## Project Files

- `main.py` – Basic BMI calculator.
- `gui.py` – Advanced BMI calculator with graphical interface.
- `README.md` – Project documentation.
